Nice VPN v1.0.0 — نسخه پرتابل ویندوز (64 بیتی)
================================================

اجرا:
  1) فایل زیپ را در یک پوشهextract کنید (مسیر بدون حروف فارسی بهتر است).
  2) روی NiceVPN.bat دوبار کلیک کنید — برنامه اجرا و آیکونش در system tray می‌رود.
  3) یک سرور انتخاب کنید و دکمه بزرگ وسط را بزنید.

نکته‌ها:
  • اگر برنامه باز نشد، اول NiceVPN-debug.bat را اجرا کنید تا علت را ببینید.
    (رایج‌ترین علت: نصب نبودن Microsoft Visual C++ Redistributable —
     از https://aka.ms/vs/17/release/vc_redist.x64.exe نصب کنید.)
  • برای ساخت شورتکات دسکتاپ با آیکون: MakeShortcut.bat را اجرا کنید.
  • «پروکسی سیستم خودکار»: تنظیمات WinINET ویندوز روی 127.0.0.1:10809 تنظیم می‌شود؛
    مرورگرها و اکثر برنامه‌ها از آن پیروی می‌کنند.
  • برنامه‌هایی که پروکسی سیستم را رعایت نمی‌کنند، با این تنظیمات ترمینال هدایت شوند:
        set http_proxy=http://127.0.0.1:10809
        set https_proxy=http://127.0.0.1:10809
  • پورت‌ها: SOCKS5 = 127.0.0.1:10808  |  HTTP = 127.0.0.1:10809
  • برای خروج کامل: راست‌کلیک روی آیکون tray ← خروج.
